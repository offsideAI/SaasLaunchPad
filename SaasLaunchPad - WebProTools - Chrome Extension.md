# SaasLaunchPad - WebProTools - Chrome Extension

## Overview
**SaasLaunchPad** (WebProTools) is a Chrome extension designed to enhance web browsing by providing tools to blur specific text content and remove advertisements from web pages. It is built using **TypeScript**, **Webpack**, and **Tailwind CSS**.

## Features
- **Text Blurring**: Automatically blurs specified text on web pages to protect sensitive information or reduce distractions.
- **Ad Removal**: Detects and removes common advertisement elements from the current page.
- **Data Retrieval**: Retrieves the title and URL of the active tab.
- **Host Exclusion**: Allows users to exclude specific websites from the extension's effects.
- **Toggle Control**: Easily enable or disable the extension via the popup interface.

## Installation & Setup

### Prerequisites
- Node.js and npm installed.
- Google Chrome browser.

### Build Instructions
1.  Navigate to the extension directory:
    ```bash
    cd saaslaunchpad-chrome-extension
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Build the extension:
    - For production:
      ```bash
      npm run build
      ```
    - For development (watch mode):
      ```bash
      npm run start
      ```

### Loading into Chrome
1.  Open Chrome and navigate to `chrome://extensions/`.
2.  Enable **Developer mode** in the top right corner.
3.  Click **Load unpacked**.
4.  Select the `dist` directory generated by the build process.

## Architecture

The extension follows the standard Chrome Extension Manifest V3 architecture:

- **Manifest (`static/manifest.json`)**: Defines the extension's configuration, permissions, and entry points.
- **Background Script (`src/background.ts`)**: A service worker that handles extension lifecycle events and maintains the badge state.
- **Content Script (`src/content.ts`)**: Runs in the context of web pages to manipulate the DOM (blur text, remove ads).
- **Popup (`src/popup.ts` & `src/popup.html`)**: The main user interface for interacting with the extension.
- **Options (`src/options.ts` & `src/options.html`)**: A dedicated page for configuring advanced settings (e.g., excluded hosts).

## Key Components

### 1. Manifest Configuration
- **Permissions**:
    - `activeTab`: Access to the currently active tab.
    - `scripting`: Ability to execute scripts.
    - `downloads`: (Listed but currently unused in visible logic).
    - `storage`: Persist user settings (enabled state, text to blur, excluded hosts).
- **Host Permissions**: Matches `<all_urls>` to function on any website.

### 2. Background Service Worker (`src/background.ts`)
- Initializes the extension state on startup and installation.
- Updates the extension icon badge text ("ON"/"OFF") based on the enabled state.
- Listens for messages but primarily logs them in the current implementation.

### 3. Content Script (`src/content.ts`)
- **Text Blurring**:
    - Observes DOM changes using `MutationObserver`.
    - Recursively scans text nodes.
    - Blurs the parent element if the text content matches the configured item.
    - Avoids double-blurring and respects the "enabled" state.
- **Ad Removal**:
    - Responds to `removeAds` messages.
    - Targets elements matching common ad selectors (e.g., `div[data-testid="StandardAd"]`, `iframe[src*="ad"]`).
    - Uses a `MutationObserver` to remove dynamically added ads.
- **Communication**:
    - Listens for configuration updates (enabled/disabled, excluded hosts) from the popup.
    - Responds with page title and URL.

### 4. Popup Interface (`src/popup.ts`)
- **Toggle Switch**: Enables or disables the extension globally.
- **Input Field**: Sets the text string to be blurred on web pages.
- **Buttons**:
    - **Retrieve Data**: Fetches and displays the current tab's title and URL.
    - **Blur Now**: Triggers an immediate blur pass on the active tab with the current text.
    - **Remove Ads**: Triggers the ad removal logic on the active tab.
    - **Runtime Message**: Sends a test message to the background script.
- **Status Feedback**: Displays success or error messages to the user.

### 5. Options Page (`src/options.ts`)
- Provides a UI to manage the `excludeHost` setting.
- Updates the storage and notifies active tabs of the configuration change.

## Data Storage
The extension uses `chrome.storage.sync` to persist settings across devices:
- `enabled`: Boolean flag for the extension's active state.
- `item`: The string of text to blur.
- `excludeHost`: The hostname where the extension should be inactive.

## Build System
- **Webpack**: Bundles the TypeScript code and resources.
- **Loaders**:
    - `ts-loader`: Compiles TypeScript.
    - `css-loader` & `postcss-loader` (with Tailwind): Processes CSS.
    - `copy-webpack-plugin`: Copies static assets (manifest, HTML, icons) to the `dist` folder.
